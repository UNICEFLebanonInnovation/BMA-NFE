Noto Naskh Arabic Bold, version 2.004, is bundled unchanged for embedding in
MSCC/Makani examination cards. Its Naskh letterforms preserve the Arabic
appearance of the supplied card when Word or LibreOffice opens it without
an installed Arabic Times New Roman font. Latin text uses Times New Roman.

Source: [Noto fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoNaskhArabic),
distributed by Debian's `fonts-noto-core` package. Copyright 2019–2020 Google
LLC. The [SIL Open Font License 1.1](OFL.txt) permits redistribution and
embedding. The font's embedding permission (`OS/2.fsType`) is unrestricted.

The complete font is embedded so names remain editable; no child's personal
information or fonts extracted from the reference PDF are bundled.
