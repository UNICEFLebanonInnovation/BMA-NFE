# Student Registration Compiler - Interactive Code Wiki

Welcome to the **Student Registration Compiler** Interactive Code Wiki. This comprehensive knowledge base explains the entire system architecture, user workflows, administration tasks, and codebase details.

1. **[End User Guide](end_user.md)**: For operators, teachers, and field staff who use the system daily to register students, track attendance, and manage services.
2. **[Administrator Guide](admin.md)**: For Ministry IT teams and system administrators responsible for deployment, role management, background exports, and system monitoring.
3. **[Developer Guide](developer.md)**: For software engineers maintaining or extending the codebase, detailing the Django architecture, database models, frontend framework, and async task processing.
