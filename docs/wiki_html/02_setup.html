2. Setup & Installation

This guide walks you through running the project locally using Docker Compose — the recommended approach, since it replicates production services (PostgreSQL, Redis, Celery).

Prerequisites

Tool Minimum version Notes
Docker 24+
Docker Compose 2.x (Compose V2) Use docker compose or docker-compose
Git Any recent
Python 3.10+ Only needed if running outside Docker

1. Clone the Repository

git clone <repo-url>
cd BMA-DOCS

2. Configure Environment Variables

cp env.example .env

Open .env and fill in the required values. For local development, the minimum required set is:

# Django
DJANGO_SECRET_KEY=<generate-a-50-char-random-string>
DJANGO_DEBUG=True
DJANGO_ALLOWED_HOSTS=localhost,0.0.0.0,127.0.0.1

# Database (matches the docker-compose postgres service)
POSTGRES_HOST=postgres
POSTGRES_PORT=5432
POSTGRES_DB=mscc_10012023
POSTGRES_USER=postgresuser
POSTGRES_PASSWORD=mysecretpass
DATABASE_URL=postgres://postgresuser:mysecretpass@postgres:5432/mscc_10012023

# Redis (matches the docker-compose redis service)
CELERY_BROKER_URL=redis://redis:6379/0

# File storage — use local filesystem for development
DJANGO_DEFAULT_FILE_STORAGE=django.core.files.storage.FileSystemStorage

For Azure Blob Storage, Firebase, Sentry, and email variables, see Environment Variables reference.

3. Start Docker Services

docker-compose -f local.yml up --build

This starts:
- django — Django development server on port 8000
- postgres — PostgreSQL on port 5432
- redis — Redis on port 6379
- celeryworker — Celery worker
- celerybeat — Celery beat scheduler
- flower — Celery monitoring UI on port 5555
- mailhog — Local SMTP catcher on port 8025

4. Run Database Migrations

docker-compose -f local.yml run --rm django python manage.py migrate

5. Create a Superuser

docker-compose -f local.yml run --rm django python manage.py createsuperuser

6. Load Initial Data (Optional)

# Load location tree (governorates, cazas, cadasters)
docker-compose -f local.yml run --rm django python manage.py loaddata locations

# Load nationality reference data
docker-compose -f local.yml run --rm django python manage.py loaddata nationalities

7. Access the Application

URL Service
http://localhost:8000 Application
http://localhost:8000/admin/ Admin panel (Jazzmin)
http://localhost:5555 Flower (Celery monitor)
http://localhost:8025 Mailhog (caught emails)

Running Without Docker

If you prefer to run without Docker:

# Create and activate a virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements/local.txt

# Set environment variables
export DJANGO_SETTINGS_MODULE=config.settings.local
export DATABASE_URL=postgres://postgresuser:mysecretpass@localhost:5432/mscc_10012023

# Start PostgreSQL and Redis separately, then:
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

Common Development Commands

# Run tests
docker-compose -f local.yml run --rm django pytest

# Run tests with coverage
docker-compose -f local.yml run --rm django coverage run -m pytest
docker-compose -f local.yml run --rm django coverage report

# Make and apply migrations
docker-compose -f local.yml run --rm django python manage.py makemigrations
docker-compose -f local.yml run --rm django python manage.py migrate

# Open a Django shell
docker-compose -f local.yml run --rm django python manage.py shell

# Generate translation files
docker-compose -f local.yml run --rm django python manage.py makemessages -l ar
docker-compose -f local.yml run --rm django python manage.py compilemessages

# Collect static files (needed for production-like testing)
docker-compose -f local.yml run --rm django python manage.py collectstatic --no-input

Settings Files

File Used when
config/settings/base.py Always — shared base
config/settings/local.py DJANGO_SETTINGS_MODULE=config.settings.local
config/settings/production.py DJANGO_SETTINGS_MODULE=config.settings.production
config/settings/test.py When running pytest

The local settings activate:
- DEBUG = True
- Django Debug Toolbar
- Eager Celery task execution (tasks run synchronously, no worker needed)
- LocMemCache instead of Redis cache
- Mailhog for email

Troubleshooting

Port already in use:

docker-compose -f local.yml down
# then restart

Database connection refused:
Make sure POSTGRES_HOST=postgres in .env (not localhost) when using Docker.

Missing migrations:

docker-compose -f local.yml run --rm django python manage.py showmigrations
docker-compose -f local.yml run --rm django python manage.py migrate --run-syncdb

Static files 404:

docker-compose -f local.yml run --rm django python manage.py collectstatic --no-input
