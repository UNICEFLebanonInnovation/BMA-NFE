1. Project Overview

What Is This System?

The BMA Student Registration Compiler is a web-based case management and service-delivery tracking platform built for UNICEF Lebanon's Non-Formal Education (NFE) sector. It is used by NGO partner organizations, UNICEF staff, and Ministry of Education teams across Lebanon.

The system manages:

  • Child and student registration across multiple programs
  • Service delivery tracking (education, health & nutrition, youth, PSS, inclusion, digital skills)
  • Attendance recording with heatmap visualization
  • Teacher management
  • Reporting and data export (XLSX, CSV)
  • Role-based access control for ~13 distinct user roles
  • Push notifications via Firebase Cloud Messaging

The Two Main Programs

MSCC — Multi-Service Community Centers

The primary module. Partners operate community centers where children and youth receive bundled services. Every beneficiary goes through:

  1. Registration (child demographic profile, household info)
  2. Service delivery (one or more of: education assessment, remedial support, youth activities, health checks, PSS sessions, digital training, recreational activities, LEGO therapy)
  3. Attendance tracking (daily, per-center)
  4. Grading / outcome recording

CLM — Community Learning Management

The secondary module for bridging programs and informal schools:

  1. Student enrollment in bridging cycles
  2. Pre-test / post-test assessment tracking
  3. Attendance recording at the class level
  4. Teacher and center management

Who Uses It?

Role What they do
Field Staff (MSCC) Register children, record service delivery, mark attendance
Center Coordinators Manage center-level data, run reports
Partner Admins View all data across their organization's centers
UNICEF Staff Cross-partner analytics, export aggregate data
Ministry IT / Admins Manage users, system configuration, deployments
CLM Teachers Record CLM attendance
CLM Bridging Staff Manage student enrollment and assessments

Key Design Decisions

Decision Rationale
Django monolith Centralized codebase, easier to maintain by a small team
Server-rendered templates Works on slow field connections; no JS framework complexity
PostgreSQL Relational data with complex join requirements
Celery + Redis Large XLSX exports offloaded to background workers
Azure Blob Storage Scalable file storage for exported files and media uploads
Jazzmin admin Enhanced admin UI without custom front-end build
MPTT for locations Lebanon's geographic hierarchy (Governorate → Caza → Cadaster) maps naturally to a tree

Key Functional Modules

ModuleDescription
Registration ModuleHandles student enrollment and validation. Links a child profile to a programme, round, center, and class section.
Attendance ModuleTracks daily attendance per student. Supports Present, Absent, Excused, and Late statuses.
Education ModuleManages grading, assessments, and programme assignment. Tracks academic performance across subjects.
Reporting ModuleGenerates pivot tables and exports. Relies on database views for performant data aggregation.
Dashboard ModuleVisual analytics using D3 and PivotTable.js. Supports filtering by programme, center, round, and date range.
Teacher ModuleManages teacher profiles, qualifications, documents, and programme assignments.
Headcount ModuleEmergency safety reporting — staff submit status, location, and GPS data during incidents.
