11. Environment Variables

All configuration is driven by environment variables. Copy env.example to .env and populate it before starting the application.

Environment variables are loaded via django-environ in config/settings/base.py.

Required Variables

Django Core

Variable Example Description
DJANGO_SETTINGS_MODULE config.settings.local Which settings file to load
DJANGO_SECRET_KEY 50-char-random-string Required. Django's cryptographic signing key. Generate with python -c "import secrets; print(secrets.token_urlsafe(50))"
DJANGO_DEBUG True / False Enable debug mode. Must be False in production.
DJANGO_ALLOWED_HOSTS example.com,www.example.com Comma-separated list of valid hostnames
DJANGO_ADMIN_URL admin URL path for the admin panel (default admin)

Database

Variable Example Description
DATABASE_URL postgres://user:pass@host:5432/dbname Full database connection string
POSTGRES_HOST postgres DB host (use postgres in Docker)
POSTGRES_PORT 5432 DB port
POSTGRES_DB mscc_10012023 Database name
POSTGRES_USER postgresuser Database user
POSTGRES_PASSWORD mysecretpass Database password
DATABASE_SSL_ENABLED False Enable SSL for DB connection

Redis & Celery

Variable Example Description
CELERY_BROKER_URL redis://redis:6379/0 Redis URL for Celery broker
REDIS_URL redis://redis:6379/0 Redis URL for Django cache (if using Redis cache)

Optional Variables

File Storage (Azure Blob)

Leave these empty to use local filesystem storage (development default).

Variable Description
AZURE_ACCOUNT_NAME Azure Storage account name
AZURE_ACCOUNT_KEY Azure Storage account key
AZURE_CONTAINER Blob container name for media uploads
AZURE_EXPORT_CONTAINER Blob container name for export files

AWS S3 (Alternative to Azure)

Variable Description
DJANGO_AWS_ACCESS_KEY_ID AWS access key
DJANGO_AWS_SECRET_ACCESS_KEY AWS secret key
DJANGO_AWS_STORAGE_BUCKET_NAME S3 bucket name

Email

Variable Example Description
DJANGO_EMAIL_BACKEND django.core.mail.backends.smtp.EmailBackend Email backend
DJANGO_SERVER_EMAIL noreply@example.com Default sender address
DJANGO_MAILGUN_API_KEY key-xxx Mailgun API key (if using Mailgun)
MAILGUN_SENDER_DOMAIN mg.example.com Mailgun sender domain

Firebase Cloud Messaging (Push Notifications)

Variable Description
FCM_SERVER_KEY Firebase server key for push notifications
FIREBASE_API_KEY Firebase Web API key
FIREBASE_AUTH_DOMAIN Firebase auth domain
FIREBASE_PROJECT_ID Firebase project ID
FIREBASE_STORAGE_BUCKET Firebase storage bucket
FIREBASE_MESSAGING_SENDER_ID Firebase messaging sender ID
FIREBASE_APP_ID Firebase app ID
FIREBASE_MEASUREMENT_ID Firebase measurement ID (analytics)

Error Tracking

Variable Example Description
DJANGO_SENTRY_DSN https://xxx@sentry.io/xxx Sentry DSN for error tracking. If empty, Sentry is disabled.

Security (Production)

Variable Default Description
DJANGO_SECURE_SSL_REDIRECT True Redirect HTTP → HTTPS
DJANGO_SECURE_HSTS_INCLUDE_SUBDOMAINS True HSTS for all subdomains
DJANGO_CSRF_TRUSTED_ORIGINS https://example.com Trusted CSRF origins (comma-separated)

Monitoring

Variable Description
OTEL_SERVICE_NAME OpenTelemetry service name (e.g., bma-prod)
OTEL_RESOURCE_ATTRIBUTES OpenTelemetry resource attributes
NEW_RELIC_LICENSE_KEY New Relic license key (if used)

External APIs

Variable Description
UNIQUE_ID_API_URL Endpoint for the Unique ID external service
UNIQUE_ID_API_TOKEN_URL Token endpoint for Unique ID service authentication
UNIQUE_ID_API_USERNAME Username for Unique ID service
UNIQUE_ID_API_PASSWORD Password for Unique ID service
UNIQUE_PROGRAMMES_API_URL Programmes API endpoint

Feature Flags

Variable Default Description
COMPRESS_ENABLED True Enable django-compressor for CSS/JS compression
DJANGO_ACCOUNT_ALLOW_REGISTRATION True Allow new user self-registration
DJANGO_READ_DOT_ENV_FILE True Read .env file automatically on startup

Loading Variables

Variables are loaded in config/settings/base.py at the top:

import environ
env = environ.Env()

# If DJANGO_READ_DOT_ENV_FILE=True, reads from .env in the project root
READ_DOT_ENV_FILE = env.bool('DJANGO_READ_DOT_ENV_FILE', default=False)
if READ_DOT_ENV_FILE:
    environ.Env.read_env(str(ROOT_DIR.path('.env')))

In Docker, variables are passed via the environment: section in local.yml / production.yml, or via .env file reference.

Generating a Secret Key

python -c "import secrets; print(secrets.token_urlsafe(50))"

Never commit the actual secret key to version control.
