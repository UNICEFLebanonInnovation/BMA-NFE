6. API & URL Reference

URL Structure

The root URL configuration is in config/urls.py. URLs are organized by functional module:

Prefix Module Notes
/admin/ Django admin (Jazzmin) URL can be overridden via DJANGO_ADMIN_URL env var
/accounts/ django-allauth Login, logout, password reset
/users/ users app Profile, language switcher
/mscc/ mscc app All MSCC program views
/clm/ clm app All CLM program views
/api/ DRF + drf-spectacular JSON API and schema docs
/about/ Static page
/landing-page/ Landing page
/login-success/ Post-login redirect
/serve-file/<path>/ Media file serving

Authentication

All API endpoints require authentication:
- Session auth — Works automatically for browser-based requests (same session cookie)
- Token auth — Pass Authorization: Token <token> header for programmatic access

To obtain a token:

curl -X POST http://localhost:8000/api/token/ \
  -d '{"username": "user", "password": "pass"}' \
  -H "Content-Type: application/json"

URL Naming Conventions

Views use Django's name parameter on path() for reverse URL lookups. Examples:

# Reverse a URL in Python
from django.urls import reverse
url = reverse('mscc:child-add')

# In templates
{% url 'mscc:child-profile' pk=registration.pk %}

Each app's urls.py sets app_name to namespace the URLs:

app_name = 'mscc'
