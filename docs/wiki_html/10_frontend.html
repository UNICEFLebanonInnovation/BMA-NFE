10. Frontend Guide

Overview

The frontend is server-rendered — Django templates generate complete HTML pages. There is no single-page application framework (no React, Vue, or Angular). JavaScript is used selectively for interactivity on top of server-rendered HTML.

This approach was chosen deliberately:
- Works on slow field connections in Lebanon
- No complex build pipeline
- Simpler maintenance for a small team

Base Template

base.html defines the outer shell:
- HTML <head> with Bootstrap, Font Awesome, custom CSS
- Top navbar (includes user menu, language switcher)
- Sidebar navigation (MSCC / CLM / Admin links, filtered by user group)
- {% block content %} — main content area
- Footer
- JS includes (jQuery, Bootstrap bundle, Select2, app.js)

Every page template extends base.html:

{% extends "base.html" %}
{% block content %}
  <h1>My Page</h1>
{% endblock %}

Common Template Patterns

Displaying User-Scoped Data

Templates receive context from the view. Views always pass the logged-in user's partner/center context:

# In a view's get_context_data:
context['partner'] = self.request.user.partner
context['registrations'] = Registration.objects.filter(center=self.request.user.center)

Group-Based Conditional UI

{% load has_group %}

{% if request.user|has_group:"MSCC_FULL" %}
  <button>Export All Data</button>
{% endif %}

{% if request.user|has_group:"MSCC_UNICEF" %}
  <a href="{% url 'mscc:dashboard' %}">Analytics Dashboard</a>
{% endif %}

AJAX Form Submission

Service delivery forms on the child profile page are submitted via AJAX (no full page reload):

// Pattern used throughout child_profile.html
$('#education-form').on('submit', function(e) {
    e.preventDefault();
    $.ajax({
        url: $(this).attr('action'),
        method: 'POST',
        data: $(this).serialize(),
        headers: {'X-CSRFToken': getCookie('csrftoken')},
        success: function(response) {
            if (response.success) {
                showToast('Service saved successfully');
                refreshServiceTable();
            } else {
                showFormErrors(response.errors);
            }
        }
    });
});

All AJAX POST endpoints return:

{"success": true}
// or
{"success": false, "errors": {"field_name": ["error message"]}}

CSRF Token in AJAX

For all AJAX requests, include the CSRF token:

function getCookie(name) {
    // Standard Django CSRF cookie helper
    let cookieValue = null;
    if (document.cookie && document.cookie !== '') {
        document.cookie.split(';').forEach(cookie => {
            if (cookie.trim().startsWith(name + '=')) {
                cookieValue = decodeURIComponent(cookie.trim().slice(name.length + 1));
            }
        });
    }
    return cookieValue;
}

Select2 Autocomplete

Foreign key dropdowns use Select2 with django-autocomplete-light for server-side search:

<!-- In a form template -->
{{ form.school|as_crispy_field }}

# In the form class:
class RegistrationForm(forms.ModelForm):
    school = ModelChoiceField(
        queryset=School.objects.all(),
        widget=autocomplete.ModelSelect2(url='school-autocomplete')
    )

The autocomplete view (/school-autocomplete/) returns JSON filtered by the search term.

Attendance Heatmap (D3.js)

The attendance heatmap at /mscc/attendance-heatmap/ uses D3.js to render a calendar-style grid showing daily attendance rates per child.

Data is fetched from /api/attendance-heatmap-data/ as JSON. The D3 code lives in student_registration/static/js/heatmap.js.

Dashboard Charts (Chart.js)

Dashboard pages use Chart.js for bar/pie/line charts. Data is loaded via AJAX from /mscc/dashboard-data/ (returns JSON with pre-aggregated counts).

// Pattern in dashboard.html
fetch('/mscc/dashboard-data/?filter=...')
    .then(r => r.json())
    .then(data => {
        new Chart(document.getElementById('registrations-chart'), {
            type: 'bar',
            data: data.registrations_by_month,
        });
    });

In production, collectstatic copies all static files to STATIC_ROOT and WhiteNoise serves them directly from Gunicorn (no Nginx static serving needed).

Internationalization (i18n)

The UI supports Arabic and English. Users switch languages via /users/set-language/<language>/.

Templates use Django's {% trans %} and {% blocktrans %} tags:

{% load i18n %}
<h1>{% trans "Child Registration" %}</h1>

RTL (right-to-left) layout is handled by Bootstrap's RTL stylesheet, loaded conditionally based on the active language.

To add a new translated string:

# Extract strings from templates and Python files
python manage.py makemessages -l ar

# Edit locale/ar/LC_MESSAGES/django.po
# Then compile:
python manage.py compilemessages

Forms with Crispy Forms

Most forms use django-crispy-forms with the Bootstrap 5 template pack:

from crispy_forms.helper import FormHelper
from crispy_forms.layout import Layout, Row, Column, Submit

class RegistrationForm(forms.ModelForm):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.helper = FormHelper()
        self.helper.layout = Layout(
            Row(
                Column('first_name', css_class='col-md-4'),
                Column('father_name', css_class='col-md-4'),
                Column('last_name', css_class='col-md-4'),
            ),
            Submit('submit', 'Save', css_class='btn btn-primary'),
        )
