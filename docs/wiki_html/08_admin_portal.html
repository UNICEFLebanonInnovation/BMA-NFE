8. Admin Portal Guide

Overview

The admin portal is available at /admin/ (or the path set in DJANGO_ADMIN_URL). It uses Jazzmin — a Jinja-compatible Bootstrap 4 skin for Django admin.

Access the admin panel with a superuser account. Creating one:

python manage.py createsuperuser

Jazzmin Configuration

All branding and navigation is configured in JAZZMIN_SETTINGS inside config/settings/base.py.

Current Settings Summary

JAZZMIN_SETTINGS = {
    "site_title": "BMA Sector",
    "site_header": "BMA Sector",
    "welcome_sign": "Welcome to BMA Admin",
    "copyright": "MEHE",
    "show_sidebar": True,
    "navigation_expanded": True,
}

- Import/Export enabled (django-import-export)

- List display: user, token (truncated), created

- Filters: partner, center, round, programme_type, status, deleted

- Standard CRUD

- List display: name, current_round, start_date, end_date

Packages / ProvidedServices
- Inline within Registration admin

Customizing Admin Classes

Each model's admin class lives in its app's admin.py. Standard patterns used throughout the project:

from django.contrib import admin
from import_export.admin import ImportExportModelAdmin
from rangefilter.filter import DateRangeFilter

@admin.register(MyModel)
class MyModelAdmin(ImportExportModelAdmin):
    list_display = ['name', 'partner', 'created']
    list_filter = [
        'partner',
        ('created', DateRangeFilter),  # Date range picker
    ]
    search_fields = ['name']
    autocomplete_fields = ['partner', 'location']  # Select2 autocomplete
    readonly_fields = ['created', 'modified']

    # For import/export resource definition:
    resource_class = MyModelResource

Import/Export

Most key models support bulk import (Excel/CSV upload) and export via django-import-export.

To export from admin:
1. Navigate to the model list
2. Select rows (or select all)
3. Choose "Export" from the Actions dropdown
4. Select format (XLSX, CSV, JSON, etc.)

To import:
1. Click the "Import" button at the top of the model list
2. Upload a CSV or XLSX file following the template format
3. Review the diff preview
4. Confirm import

Export resource definitions are in each app's resources.py.

Admin Performance Tips

The admin panel can be slow on large datasets (100,000+ registrations). Tips:

  1. Always use list_select_related to avoid N+1 queries on FK fields in list_display
  2. Use raw_id_fields for high-cardinality FK fields (child, registration) instead of autocomplete_fields if the dataset is huge
  3. Paginate aggressively — default is 100 rows per page; reduce to 50 for heavy views
  4. Avoid count() on large tables — Django admin runs COUNT(*) for pagination; consider setting show_full_result_count = False
class HeavyModelAdmin(admin.ModelAdmin):
    list_per_page = 50
    show_full_result_count = False
    list_select_related = ['partner', 'center']

Admin URL Customization

The admin URL is configurable via DJANGO_ADMIN_URL environment variable to avoid exposing the default /admin/ path in production:

DJANGO_ADMIN_URL=secret-admin-path

The admin will then be at /secret-admin-path/.
